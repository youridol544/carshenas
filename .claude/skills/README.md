## Deliberately not used

Recorded with reasons in `docs/research/2026-09-18-ui-ux-design-for-agents.md` and `docs/research/2026-09-21-react-19-nextjs-16-knowledge-for-agents.md`: Anthropic's `frontend-design` plugin (auto-updates, aims for a new look per project), the `skills` CLI (telemetry on by default), ui-ux-pro-max (no RTL, generic palettes), Vercel's `web-design-guidelines` skill (fetches its rules from an unpinned URL on every run), Vercel's `next-best-practices` (retired by the Next.js team in favour of the bundled docs), `next-dev-loop` (requires agent-browser, which conflicts with ADR-0002), `react-doctor` (telemetry, overlaps ESLint), the shadcn skill and MCP (only when shadcn/ui is adopted, ADR-0005).

Database material, recorded with evidence in `docs/research/2026-09-27-database-research/harness.md` (read on 2026-09-27; `database/references/craft.md` rewrites what we keep, corrected and with car-listing examples):

- Read, not vendored: Supabase's `supabase-postgres-best-practices` (indexes every WHERE and JOIN column by default, idempotent DDL, `numeric(10,2)` money that overflows at a 1.5 billion toman price, shop-table examples) and Tiger Data's general `design-postgres-tables` and `postgres-database-migration` skills (two false limitations, two syntax errors and a wrong lock level reproduced in the lab; "55% more indexes" counted as an improvement).
- PlanetScale's `database-skills` (fetches its reference files from an unpinned branch at run time, recommends its own hosting, an example `CREATE TABLE user (` that does not parse) and Neon's `agent-skills` (fetches a skill at run time; Neon-only content).
- The wshobson and VoltAgent database agents (an uncredited derivative of Tiger Data's skill, polyglot persistence as a selling point, invented performance targets, write tools).
- Every hosted database MCP server (Supabase, Neon, PlanetScale, Prisma Postgres, Tiger Data's documentation server): network calls at run time and US accounts. Postgres MCP Pro (unrestricted by default, a read-only bypass reported on 2026-06-06 and unfixed at its last release). Anthropic's archived reference PostgreSQL MCP server (its read-only mode was escaped by stacked statements). The agent uses `pnpm db:psql` with the read-only role instead.
- Atlas migration linting (its PostgreSQL lock analyzers need Atlas Pro and `atlas login`, telemetry on by default); Squawk covers the migrations.

## Rules for adding one

1. Read every file of it first. Copy it at a pinned commit into the repo; do not install through a CLI or marketplace that updates it later, and do not use a skill that fetches instructions from the network when it runs.
2. Record origin, licence and commit in this file (and a `VENDORED.md` next to copied files), including any edit you made.
3. Project rules win. A skill in a developer's `~/.claude/skills` is not part of the project; where one disagrees with `.claude/rules/` or `react-patterns` (Vercel's `react-best-practices` predates `useEffectEvent` and the React Compiler guidance, for example), follow the project.
4. A skill nobody has invoked for a month is deleted (AGENTS.md).
