## Genkit (JS)

Packages: `genkit` 1.42.0; `@genkit-ai/compat-oai` 1.42.0 (the current OpenAI-compatible plugin, exporting `.`, `/openai`, `/deepseek`, `/xai`); `@genkit-ai/google-genai` 1.42.0; the official `@genkit-ai/anthropic` 0.5.0, which replaces the community `genkitx-anthropic` 0.30.0 (on `@anthropic-ai/sdk ^0.39.0`, last published 2026-01-29, about 2,000 downloads a week).

1. **Metis.**
   - How output works: `output.format` picks a formatter, `json` by default with a schema (`ai/src/formats/index.ts:47-60`), which sets `constrained: true` (`formats/json.ts:20-27`). If the model declares `supports.constrained: 'all'` (or `'no-tools'` without tools) the plugin maps the schema to its native parameter; otherwise the `simulateConstrainedGeneration` middleware appends "Output should be in JSON format and conform to the following schema:" and the schema to the prompt and strips the native format (`ai/src/model.ts:366-387`, `ai/src/model/middleware.ts:544-583`). Replies are parsed leniently with JSON5 and partial JSON (`ai/src/extract.ts:30-107`).
   - OpenAI (works): `openAICompatible({name, baseURL, apiKey, fetch, maxRetries…})` passes those into `new OpenAI()` (openai 4.104.0; `plugins/compat-oai/src/index.ts:119-130`), Chat Completions only (`model.ts:664, 697`). On the wire `response_format: {type: 'json_schema', json_schema: {name: 'output', schema}}` **with no `strict`** (`model.ts:607-621`), so OpenAI's schema guarantee is never requested; only model refs that declare `constrained` get it (the `/openai` GPT refs do, `openai/gpt.ts:25-34`; a generic `openAICompatible` model does not, `model.ts:800-808`). `maxOutputTokens` is dropped ("unused", `model.ts:570`).
   - Anthropic (weak): the plugin's options are `apiKey` and `apiVersion` (`plugins/anthropic/src/types.ts:35-45`) and it builds `new Anthropic({apiKey})` per request (`models.ts:162-169`), so the base URL can come only from the process-wide `ANTHROPIC_BASE_URL`. The default "stable" runner throws "Only text output format is supported for Claude models currently" for any JSON output (`runner/stable.ts:220-224`). With `apiVersion: 'beta'`, and only for its listed models, it sends the **deprecated** `output_format: {type: 'json_schema', schema}` with a beta list including `structured-outputs-2025-11-13`, to `/v1/messages?beta=true` (`runner/beta.ts:87-91, 345-353`). It never sets `output_config.format`; a hand-set `config.output_config` passes through untouched (`types.ts:176-190`) but bypasses Genkit's schema handling (not tried).
   - Gemini (works): `googleAI({apiKey, baseUrl: 'https://api.metisai.ir'})` builds `${baseUrl}/v1beta/models/{m}:generateContent` with `x-goog-api-key` (`plugins/google-genai/src/googleai/client.ts:380-386, 459-473`); structured output is `responseMimeType` plus `responseJsonSchema`, or `responseSchema` with `legacyResponseSchema: true` (`googleai/gemini.ts:835-861`).
   - DeepSeek: `openAICompatible` with Metis's URL; its refs do not declare `constrained` (`deepseek/deepseek.ts:46-54`), so a schema goes into the prompt; `output: {format: 'json'}` without a schema sends `json_object` (`model.ts:617-620`).
2. **Validation and re-ask.** **zod 3 only**: `@genkit-ai/core` depends on `zod ^3.23.8` and converts with `zod-to-json-schema` (`core/package.json:46`, `core/src/schema.ts:97`); issue #3470, "Support zod 4 in @genkit-ai/core", open since 2025-08-24, where a maintainer wrote on 2026-02-27, "We have zod4 planned for 2.0 release since it's a breaking change... don't have a solid ETA yet". With zod 4.6.5 we would pass `output.jsonSchema` and parse ourselves. Output is checked with ajv against the JSON Schema (`schema.ts:17-27, 297-310`), so zod refinements never run; a failure throws `ValidationError` (`INVALID_ARGUMENT`) whose message includes "Provided data:" with the model's output (`schema.ts:66-82`). Nothing re-asks with the error. `retry` (deprecated in core for `@genkit-ai/middleware` 0.10.0) retries the model call 3 times on UNAVAILABLE, DEADLINE_EXCEEDED, RESOURCE_EXHAUSTED, ABORTED, INTERNAL and any non-Genkit error, from 1 s doubling with jitter to a 60 s cap (`ai/src/model/middleware.ts:310-316, 349-430`, `plugins/middleware/src/retry.ts:91-97, 140-165`); `fallback` switches models on those plus NOT_FOUND and UNIMPLEMENTED (`middleware.ts:318-326, 470-535`); neither sees schema failures.
3. **Streaming and tools.** `generateStream`, `defineTool`, interrupts; the tool loop is capped by `maxTurns`, 5 by default (`generate/action.ts:514`).
4. **Usage.** inputTokens, outputTokens, totalTokens, thoughtsTokens, cachedContentTokens and a free-form `custom` map (`ai/src/model-types.ts:260-275`); compat-oai fills prompt, completion and total only (`model.ts:701-707`); the Anthropic stable runner adds cache read and creation in `custom` (`stable.ts:475-487`), the beta runner input and output only (`beta.ts:434-437`); Gemini adds thoughts and cached tokens (`gemini.ts:925-933`). The answering model and response id only in `response.raw` or `custom`; no provider request id; no cost.
5. **OpenTelemetry.** Every action becomes a span with its full JSON input and output as `genkit:input` and `genkit:output` (`core/src/action.ts:570-571, 605`, `core/src/tracing/instrumentation.ts:221-243`), **with no switch in core to turn that off** (redaction exists only in the Google Cloud exporter, `plugins/google-cloud/src/types.ts:100-103`). On the first span Genkit starts its own OpenTelemetry Node SDK (`@opentelemetry/sdk-node` 0.52; `core/src/tracing.ts:32-40, 97-106`); the opt-out `disableGenkitOTelInitialization()` is `@hidden` and "unstable" (`tracing.ts:121-133`); interaction with our own setup UNVERIFIED. The default exporter posts only to `GENKIT_TELEMETRY_SERVER` (`exporter.ts:144-150`); Firebase monitoring only on request (`tracing.ts:50-70`); the CLI and Dev UI send Google Analytics until `genkit config set analyticsOptOut true` (`genkit-tools/common/src/utils/analytics.ts:228-238`).
6. **Test doubles.** `genkit/testing`: `mockModel` (a reply, a callback with `sendChunk`, or a queue that can hold errors; `supports.constrained: 'all'` by default), `echoModel`, `testModels` (`ai/src/testing/mock-model.ts:72-105`, added 2026-07-15 in #5475). compat-oai accepts `fetch`; the Anthropic plugin has only an internal `__testClient` symbol (`types.ts:30, 51-53`); the Gemini plugin uses the global `fetch` (`client.ts:542`). No record and replay.
7. **Typed outcomes.** Finish reasons stop, length, blocked, aborted, failed, interrupted, other, unknown (`model-types.ts:283-292`); only `blocked` (`GenerationBlockedError`) and a missing message (`GenerationResponseError`) throw (`response.ts:102-116`). An Anthropic `refusal` becomes `other` (`stable.ts:442-459`, `beta.ts:524-525`); compat-oai never reads OpenAI's `refusal`. `length` is not an error, and the partial-JSON parser (`extract.ts:90-94`) can turn a cut reply into an object that passes a lenient schema; in compat-oai a cut JSON reply hits a bare `JSON.parse` (`model.ts:408-413`) whose error is not a Genkit error, so `retry` re-runs the same request. Gemini SAFETY becomes blocked (`common/converters.ts:396-404`); no candidates raises "No valid candidates returned." (`gemini.ts:914-919`). Nothing depends on log-probabilities.
8. **Registry, prompts, cache.** A registry of named actions (flows, prompts, tools, schemas); Dotprompt `.prompt` files with `model`, `config` and input and output schemas in YAML front matter (Picoschema or a registered schema, so zod 3); variants (`name.variant.prompt`) as versioning; `promptDir` defaults to `./prompts` (`genkit/src/genkit.ts:663-666`); `genkit eval:flow` through the CLI. No response cache, content-hash versions or prompt optimiser.
9. **Maintenance and licence.** Apache-2.0, 6,457 stars, pushed 2026-09-29, 819 open issues and pull requests, 158 contributors. genkit 1.42.0 (2026-09-01), v1.41.0 (2026-08-11), v1.40.1 (2026-07-21), v1.40.0 (2026-07-17), v1.39.0 (2026-06-26); the CLI 1.43.0 (2026-09-17). 251 commits since 2026-07-01, 45 touching `js/`. Weekly downloads: genkit 253,372, google-genai 162,539, compat-oai 36,081, anthropic 15,852. 1.0 went GA as 1.0.4 on 2025-02-07 (npm 1.0.0 to 1.0.3 belong to an unrelated 2018 package), then 42 minor releases; 2.0, which brings zod 4, has no date.
10. **Footprint.** The four packages resolve to 527 dependencies: 235 required (Express, cors, ws and get-port for the development-only reflection server; `@grpc/grpc-js`; protobufjs with a postinstall script; the OpenTelemetry Node SDK 0.52.1 with OTLP and Zipkin exporters; ajv; handlebars; a nested zod 3.25.76) and 292 optional through `@genkit-ai/firebase` (firebase-admin, Google Cloud clients, google-gax), installed by default by npm and pnpm. No native binaries; the reflection server only with `GENKIT_ENV=dev` (`genkit.ts:191`). Node ≥ 20; a Next.js App Router integration exists (`@genkit-ai/next`).

**Verdict: partial.** Gemini fits Metis natively, and it has mocks, Dotprompt and OpenTelemetry; but it is zod 3 only, its Anthropic plugin has no base-URL option and speaks only the deprecated beta `output_format`, compat-oai sends non-strict schemas, nothing re-asks with the validation error, and every span carries prompts and outputs with no switch.

## Ax (`@ax-llm/ax` 24.0.24)

1. **Metis.**
   - Signatures (`'listingText:string -> price:number'`, or the builder `f().input().output()`, which also takes zod) are rendered through its `dsp/dspy.md` template into `<identity>`, `<input_fields>`, `<output_fields>`, `<task_definition>` and `<formatting_rules>` sections (`dsp/prompt.ts:184-322`, `agent/templates/dsp/dspy.md:29-38`), with inputs as `Title: value` lines (`prompt.ts:1276-1284`). **Ax writes the prompt around our instructions.**
   - For flat signatures there is no native schema: the model is told to "Return one `field name: value` pair per line…" and Ax's extractor parses the fields (`dspy.md:35`, `dsp/response/nonStreaming.ts:192-197`). Native structured output applies only when a field is an object or an array of objects, or with `.useStructured()` (`dsp/generate.ts:214-228`, `sig.ts:259-282`), choosing `native` (`{type: 'json_schema', schema: {name: 'output', strict: true, schema}}`, `generate.ts:1297-1316`), `function` (a synthetic `__axOutput` tool) or `json_object` from each provider's capability list; an explicit unsupported `structuredOutputMode` fails before any request (`generate.ts:245-276`).
   - On the wire: OpenAI `response_format` json_schema with `strict: true` (`ai/openai/api.ts:506-517`); Anthropic the current `output_config.format` (`ai/anthropic/api.ts:898-917, 944`); Gemini `responseMimeType` plus `responseJsonSchema` (`ai/google-gemini/api.ts:1438-1448`).
   - Base URLs: `ai({name: 'openai', apiURL: 'https://api.metisai.ir/openai/v1'})` calls `/chat/completions` (`openai/api.ts:443, 1137-1144`), except that `name: 'openai'` sends the GPT-6 family to `<apiURL>/responses` (`ai/wrap.ts:265-270`); `new AxAIOpenAI({apiURL})` stays on Chat Completions. The Anthropic and Gemini classes hard-code their makers' URLs and ignore `apiURL` (`anthropic/api.ts:1464-1478`, `google-gemini/api.ts:2549-2563`) but have a public `setAPIURL()` (`ai/base.ts:915-917`), which gives Metis's paths (read, not run). Anthropic sends `anthropic-beta: structured-outputs-2025-11-13, web-search-2025-03-05` by default (`anthropic/api.ts:49-57, 1469-1478`), replaceable with `setHeaders()`; Metis's acceptance UNVERIFIED. DeepSeek: `ai({name: 'deepseek', apiURL})` honours the URL (`ai/provider_profiles.ts:688-689`) with `function` and `json_object` as its strategies (`provider_profiles.generated.ts:710`), so `structuredOutputMode: 'json_object'`. `options.fetch` per service or per call.
2. **Validation and re-ask.** zod 3 or 4 through Standard Schema (peer `^3.24.0 || ^4.0.0`); zod issues become `ValidationError("Field '<name>' failed validation: <path>: <msg>; …")` (`dsp/standardSchema.ts:280-310, 415-443`); also `f.*` constraints, `addAssert` and `addStreamingAssert`. **It re-asks with the error**: `maxRetries` defaults to 3 (`generate.ts:1957`), four attempts in all (`generate.ts:2455-2456`); the failed answer stays in memory (`nonStreaming.ts:49`) and a user turn from `getFixingInstructions()` is added (`generate.ts:2929-2941`, `prompt.ts:582-648`): `Invalid Field: <message>` for validation (`dsp/errors.ts:45-59`), `Follow these instructions: <message>.` for an assertion (`dsp/asserts.ts:19-38`); for example "Required field not found: 'Price' (number). Add a line starting with the exact label followed by a colon…" (`errors.ts:76-84`) or "Structured output must be one JSON object with no prose or Markdown fences." (`nonStreaming.ts:176-181`). Exhausted retries throw `AxGenerateError` with "Generate failed: Unable to fix validation error: <msg>" and "LLM Output:" followed by the last answer (`generate.ts:2983-2993, 4033-4064`). Separately, HTTP retries: 3 on 408, 429, 500, 502, 503, 504 and 529, honouring `Retry-After` (`util/apicall.ts:87-93, 884-898`), and server, network and timeout errors are retried at the program level too (`generate.ts:2442-2443`).
3. **Streaming and tools.** Streaming with streaming assertions; native or prompt-emulated function calls, `maxSteps` 25 by default (`generate.ts:1958`).
4. **Usage.** Prompt, completion, total, thoughts, reasoning, cache creation, cache read and service tier (`ai/types.ts:193-203`); `remoteId` (the provider's response id) and `remoteRequestId` from `x-request-id`, `request-id` or `x-goog-request-id` (`types.ts:562-575`, `base.ts:222-231`); a usage observer per call (`types.ts:211-243`); `modelUsage.model` is the requested model (`base.ts:2666-2676`); `getEstimatedCost()` uses built-in list prices (`base.ts:1749-1752`).
5. **OpenTelemetry.** Only `@opentelemetry/api`, and no spans until a `tracer` is given (`dsp/globals.ts:15-20`): an `AxGen` span with the signature name and field counts (`generate.ts:3386-3417`) and model-call spans with `gen_ai.*` model, response id, request id and usage (`base.ts:351-366, 3557-3580`). No message text on spans at this commit (`base.ts:3486-3613`), except failures: the failure message with "LLM Output:" is recorded by `span.recordException` (`generate.ts:3455-3461`); an `excludeContentFromTrace` option exists (`types.ts:1135-1136`) but the span code ignores it. Debug logging off by default (`base.ts:847`); no vendor account or telemetry.
6. **Test doubles.** `AxMockAIService`: a fixed response, a stream or a function of the request, with `shouldError`, `latencyMs` and declared capabilities (`ai/mock/api.ts:23-67`); a custom `fetch` for recorded replies.
7. **Typed outcomes.** `AxAIRefusalError(message, model, requestId, category, explanation)` (`util/apicall.ts:339-354`) for Anthropic `refusal` with `stop_details` (`anthropic/api.ts:962-978`), OpenAI `message.refusal` (`openai/api.ts:709-711`) and Gemini SAFETY, RECITATION and PROHIBITED_CONTENT (`google-gemini/api.ts:1594-1650`); **but at the program level a refusal is re-sent unchanged up to `maxRetries` and then surfaces as a generic "Unable to fix validation error: Model refused…" whose cause is a plain `Error`** (`generate.ts:2901-2904, 2983-2993`): up to four paid calls, and the refusal type lost. A `length` finish becomes "Max tokens reached before completion", thrown without retry (`nonStreaming.ts:222-226`), but that check runs after parsing, so a cut reply that does not parse is first re-asked as a validation error. Empty answers trigger a missing-field error and a re-ask. Nothing depends on log-probabilities.
8. **Registry, prompts, cache.** Programs are code; the signature's description and instruction are the prompt, and the signature hash covers them and the fields. `cachingFunction(key, value?)` keyed by sha256 of the signature hash and the inputs (`dsp/types.ts:251-254`, `generate.ts:3586-3597, 3915-3965`), without the model or its settings. Optimisers `AxGEPA`, `AxACE` and `AxBootstrapFewShot` (MIPROv2 was removed in commit d95156b, 2026-04-24), producing a serialisable `AxOptimizedProgram` (instructions, demos, model settings, `artifactFormatVersion`) that can be committed (`dsp/optimizer.ts:814-860`).
9. **Maintenance and licence.** Apache-2.0, 2,955 stars, pushed 2026-09-27, 7 open issues and pull requests, 42 contributors; 24.0.24 (2026-09-27), 24.0.23 and 24.0.22 (2026-09-25), 24.0.21 (2026-09-22), 24.0.20 (2026-09-18). **386 commits since 2026-07-01, 352 of them by one author**: one maintainer in practice. 61,760 downloads a week. 438 stable versions; 15 major versions since 10.0.1 (2024-10-21), eight in 2026 up to 24.0.0 (2026-08-19); a breaking removal shipped in a patch release, 23.0.2 (`CHANGELOG.md:743-745`); v24 removed the per-provider classes that only wrapped a profile.
10. **Footprint.** Three packages: Ax, `@opentelemetry/api`, and zod as a peer; one 22 MB bundle, ESM and CommonJS, on the global `fetch`. **Its `postinstall` writes Claude Code skills into `<project>/.claude/skills/*/SKILL.md`** and cleans up older ones there (`scripts/postinstall.mjs:1-15, 189-227`), skipped when `CI` is set or `AX_SKIP_SKILL_INSTALL=1`; pnpm 10 runs no dependency scripts that are not allowed. It also ships an `ax` CLI.

**The pass's verdict was good** (native structured output on all four routes with `.useStructured()`, a re-ask with the exact validation error, zod 4, no prompt text on spans except failures), on conditions: an exact pin given one maintainer and frequent breaking releases, `setAPIURL` for Anthropic and Gemini, `.useStructured()`, and handling refusals ourselves. The note weighs it against the AI SDK.

## TanStack AI (`@tanstack/ai` 0.63.0)

TanStack's provider-agnostic TypeScript SDK for streaming chat, tools and structured output, with UI clients. Pre-1.0: 0.0.1 on 2025-12-04, 0.63.0 on 2026-09-27, 93 releases; no alpha or beta label found.

1. **Metis.** `openaiText` uses the Responses API; `createOpenaiChatCompletions(model, key, {baseURL, headers})` uses Chat Completions with `json_schema` `strict: true` (`openai-base/src/adapters/chat-completions-text.ts:275-286`). Anthropic takes the SDK's `baseURL` and `fetch` (`ai-anthropic/src/utils/client.ts:5, 36`) but every call goes to `client.beta.messages.create` (`?beta=true`, `adapters/text.ts:381, 466`), with `output_config.format` for listed models (`text.ts:636-654, 699-701`) and a forced `structured_output` tool otherwise (`text.ts:444-478`). Gemini uses `@google/genai` with `httpOptions.baseUrl` (`ai-gemini/src/utils/client.ts:35-39`) and sends `responseSchema`, not `responseJsonSchema` (`ai-gemini/src/adapters/text.ts:439-440, 1297-1301`).
2. **Validation.** Standard Schema (docs: zod ≥ 4.2); a failure throws `StandardSchemaValidationError("Validation failed: …")` (`ai/src/activities/chat/tools/schema-converter.ts:431-476`); no re-ask; `maxRetries` is declared but unused by these adapters.
3. **Streaming and tools** are its core.
4. **Usage.** Prompt, completion and total tokens, detail fields and a provider-reported `cost` (`ai-event-client/src/index.ts:267-305`).
5. **OpenTelemetry.** `otelMiddleware` with `captureContent` off by default and a `redact` hook (`ai/src/middlewares/otel.ts:110-120, 365`).
6. **Test doubles.** None shipped (their end-to-end tests use `@copilotkit/aimock`); the SDKs accept `fetch`.
7. **Outcomes.** Anthropic `max_tokens` becomes a run error with code `max_tokens`; a refusal is folded into a normal finish (`text.ts:1488-1535`).
8. **Registry, prompts, cache, optimisers.** None.
9. **Maintenance.** MIT, 3,149 stars, 46 open issues and pull requests, 138 contributors, 442 commits since 2026-07-01 (103 by a bot), about 551,000 downloads a week.
10. **Footprint.** Core and three adapters resolve to 62 packages (openai 6, the Anthropic SDK, `@google/genai` with google-auth-library and protobufjs); ESM only, Node ≥ 18.

**Verdict: partial.** Good OpenTelemetry privacy and usage, but no re-ask, no typed refusal, no mocks, `responseSchema` for Gemini, every Anthropic call through the beta endpoint, and pre-1.0 churn aimed at chat interfaces.
