# Which models does Metis AI serve, through which API, at what price and under what terms, and does it work from Iran?

- Date: 2026-09-29
- Asked by / for: Pedrum, for CS-42. On 2026-09-29 the owner decided that Carshenas reaches its language models through Metis AI (metisai.ir). During the task the owner added TypeSafe's jev, which Metis also serves: "we have jev too. which may help us."
- Outcome: ADR-0019, accepted on 2026-09-29 with the owner's answers: the native routes; queue and retry, then fallback models, never `metis-gpt`; and jev treated as unavailable. This note's lab (`2026-09-29-metis-ai/lab/`) and its evidence folder (`2026-09-29-metis-ai/evidence/`). Inputs for CS-43 (research), CS-44 (the AI layer's library), CS-45 (the layer) and CS-46 (a model for each AI step).

## Questions

1. Which models does Metis serve? For each: provider, model, context window, structured output and tool calling. And which embedding models?
2. What is its API: base URLs, request formats, authentication and errors? Which common SDKs work against it unchanged?
3. What does it cost, how is it billed, and what rate limits apply?
4. What do its terms say about use, liability, uptime and data retention?
5. From an Iranian network, do calls to at least three models return output that is valid against a JSON Schema? How long do they take, and what do they cost?
6. What is TypeSafe's jev, and can Carshenas use it through Metis?
7. What can Carshenas fall back on when Metis, or the international link behind it, is down?

## Findings

### 1. What Metis is

- **The company.** Metis (متیس) belongs to Pegah Dadeh Kavan Sharif, a private joint-stock company registered in Iran and operating under Iranian law [M11].
- **What it sells.** It resells many providers' models through its own API, billed in rials, pay-as-you-go [M11, M6]. It also sells bots, knowledge bases (RAG), workflows, summarisers and media generation. Those products store data (finding 4).
- **What Carshenas needs.** Only the "wrapper" mode: direct model access, plus embeddings and perhaps a reranker. In that mode Metis's own features, "such as bots or function calling" (its function feature for bots), are not available. Metis also says "full coverage of every model feature is not yet in place" [M6, M1].

### 3. The API

- **One base URL and one key.** The base is `https://api.metisai.ir`, and one key (prefix `tpsg-`) serves every route [M6, M8].
- **The formats are the makers' own.** OpenAI's, Anthropic's and Gemini's, so their SDKs work unchanged (below).

| Route | Format | Authentication | Serves | Structured output, measured [L1] |
|---|---|---|---|---|

| `/anthropic` (`/v1/messages`) | Anthropic Messages [M2, M9] | `x-api-key` or Bearer (both worked) | Claude | `output_config.format` json_schema: valid |

| `/mimo/v1`, `/mimo/anthropic` | OpenAI, Anthropic [M5] | Bearer, `x-api-key` | MiMo v2.5 | not checked |

| `/api/v1/wrapper/sotoon` (not documented) | OpenAI | Bearer | `google/gemma3-27b` | json_schema: valid |

- **Model ids.** The native routes take the maker's ids: `claude-haiku-4-5` answered as `claude-haiku-4-5-20251001`. The catalogue uses Metis's own (`claude-haiku-4.5`).
  - The DeepSeek route answered as `deepseek-flash` when asked for `deepseek-v4-flash`.
  - Metis says retired DeepSeek ids are sent "silently" to `deepseek-v4-flash`, "even `deepseek-reasoner`" [M4].
  - So the answering model must be logged, not assumed.
- **Errors [L1].**
  - Metis's own failures have the shape `{timestamp, status, error, message, path}`. A missing or wrong key gets 401: "Invalid or missing API key. Send your Metis API key as 'Authorization: Bearer tpsg-<key>' or the 'x-api-key' header."
  - An unknown model gets an OpenAI-style 400 with code `model_not_supported`.
  - When a provider refuses a request, the status code is kept and the provider's error JSON arrives as a string inside `message`.
  - 402 means the balance is empty [M8].
  - SDKs raise typed errors from the status code, so error handling works. The message needs unwrapping before it is logged.
- **SDKs [L1].** Each returned schema-valid output with only the base URL and the key changed:
  - `openai` 7.23.0, on the OpenAI route and on the DeepSeek route;
  - `@anthropic-ai/sdk` 0.129.0, with `apiKey` and with `authToken`;
  - `@google/genai` 2.24.0, through `httpOptions.baseUrl`.

  Metis documents the same for Python's `openai` and `google-genai` [M1, M3] and for Claude Code [M9]. Libraries that speak these formats (the AI SDK's providers, LiteLLM, instructor) should work the same way. That is UNVERIFIED and is left to CS-44.

### 4. Money, limits, terms and data

- **Prices and billing [M10, M11].**
  - Catalogue prices are in US dollars per million tokens.
  - The account is charged in rials, "calculated from the live free-market US dollar rate", pay-as-you-go.
  - Credit is prepaid and is never refunded ("امکان بازپس گیری وجه پرداختی به هیچ عنوان وجود ندارد"). It expires after one year, and gift credit can expire sooner.
  - So the cost per 1,000 listings in tomans moves with the dollar.
- **Caching [M12, M10].** Prompt caching exists, with five-minute and one-hour cache writes. The catalogue prices cached input separately; for example `gpt-5.6-luna` charges $0.01 per million cached input tokens.
- **Rate limits.** Metis publishes none for its API.
  - The answers carry the upstream accounts' limits: OpenAI 30,000 requests and 180 million tokens per minute; Anthropic 20,000 requests, 10 million input and 2 million output tokens per minute [L1].
  - Those are Metis's own accounts, shared by its customers. How Metis divides them is UNVERIFIED.
  - None of the 67 requests in the three evidence runs got a 429, and neither did any request in the earlier trial runs that day.
  - Pacing and backing off on a 429 belong to the AI layer (CS-45), as they do for the crawler.
- **SLA [M11].**
  - Monthly uptime "above 90%" for API requests. That allows about three days of downtime a month.
  - An average network latency under 200 ms in Metis's own path.
  - Outages caused by the upstream providers are outside its responsibility and "cannot be fixed quickly".
  - Response times: under 1 hour for a full outage, under 4 hours for major slowness, and 24 working hours for billing.
- **Data [M11].**
  - In wrapper mode requests are not stored: "Metis acts only as a proxy between you and the model and has no interference, storage or monitoring of the content of your requests".
  - For API use, error logs and request metadata are kept for billing and debugging.
  - Data may be given to courts or authorities when the law requires it. The customer is told first, unless the order is confidential.
  - Bots, knowledge bases and workflows store content. Deleted conversations are kept for three months, and payment records are never deleted.
  - Deleting an account takes a written request to info@metisai.ir.
- **Use [M11].**
  - Content that is criminal under Iranian law is forbidden.
  - Metis may close an account "unilaterally and without refund" for abuse.
  - Claims are answered for 12 months.
  - An account opened with a phone number must match its owner's national ID.
- **Where the text goes.** Whatever Metis forwards reaches the upstream provider under that provider's terms. The OpenAI and Anthropic answers came through Cloudflare's Frankfurt edge (`cf-ray` ending in `-FRA`) [L1]. So a listing's personal data must be removed before its text is sent, as AGENTS.md already requires for prompts.

### 5. Reachability from Iran [L1]

- **This network routes by destination.** The lab ran on the owner's workstation. `evidence/network-2026-09-29.json` (14:08 UTC) shows which way each host is reached, without recording any address.
  - `api.metisai.ir` goes through the ISP's own path: 8 hops answer a traceroute, and a TCP connection takes 7.1 ms (median of five, DNS excluded).
  - Foreign destinations go through a local transparent proxy that exits in the United Kingdom. Cloudflare's trace reports `loc=GB`, none of 12 hops answers, and a TCP connection completes in 1.5 ms, which only a device on the local network can do.
- **The probe's own timings agree.** Metis itself answered the three error calls, in 17, 21 and 36 ms (`evidence/probe-2026-09-29.json`, `errors`). A round trip through a UK exit takes at least about 40 ms for the distance alone. So the calls reached Metis without the proxy, and every Metis call in this note came from an Iranian network.
  - The same checks, run by hand at about 13:35 UTC before the lab runs, gave the same picture: eight answering hops within 10 ms to Metis, and no replies with a 9 ms connection to Cloudflare.
- **Metis answered every request.** No request failed at the network level. The listing endpoints took 289 to 3,018 ms in the committed catalogue run.
- **Most of the time is the provider's.** OpenAI's own processing took 1,101 ms of a 1,608 ms call (`openai-processing-ms`). Gemini's took 1,199 ms of 1,540 ms (`server-timing`). So Metis and the network add about 0.3 to 0.5 s.
- **Production.** CS-37's server will sit in an Iranian data centre, where Metis is domestic traffic. The worker needs no proxy and calls no foreign endpoint.

- a Peugeot 206 with a Jalali model year;
- a Camry with a Gregorian year and «قیمت توافقی»;
- a Cerato whose text tells the model to write the price as 100 tomans.

Each listing ran twice per model. Every answer was validated with zod.

- **All 42 answers were valid.** Three routes refused `json_schema` first: DeepSeek and the two OpenAI-format wrappers. Each worked in its fallback mode.
- **Official SDKs.** The OpenAI, Anthropic and Google SDKs each returned a valid answer as well: 9 of 9 fields, in 1.8 to 2.0 s; DeepSeek took 4.4 s through the OpenAI SDK.
- **Latency.** About 1.5 to 2 s for OpenAI, Anthropic, Gemini and metis-gpt.
  - DeepSeek reasons by default, with 286 to 718 reasoning tokens here, and took 2.0 to 4.4 s.
  - Gemma on Sotoon took 5.8 to 8.6 s.
- **Cost per 1,000 extractions**, at list price, ranges from $0.13 (gpt-5.6-luna) to $3.56 (metis-gpt). Claude's structured-output mode adds its own instructions: 1,368 input tokens against OpenAI's 700.
- **DeepSeek's figure is an upper bound.** Its route served 640 of each call's 778 to 809 prompt tokens from its cache (`prompt_cache_hit_tokens`), and the lab priced them at the full input rate. At the catalogue's cached-input price ($0.028 per million) the median is about $0.00019 per call, or $0.19 per 1,000. Whether Metis bills cache hits at that price was not checked against the account's bill.
- **The injected instruction was ignored by every model.** All 14 answers on the Cerato listing kept 1,250,000,000 tomans and full paint. That is one listing, a smoke test; CS-43 studies injection properly.
- **Self-reported confidence did not tell right from wrong.** The four wrong paint answers all said 1.0; the 38 right ones said 0.85 to 1.0. The sample is small, but a review threshold cannot rest on a model's own confidence alone (CS-43, CS-52).
- **This is a sanity check, not an evaluation** (that is CS-48): three synthetic listings.
  - Most misses were real ambiguities: «کمری هیبرید» read as the model rather than a model and a trim, and «دو لکه رنگ» read as spots or as partial paint.
  - Gemma also answered in English («Peugeot», «Toyota») where the listing says «پژو» and «تویوتا».

### 7. jev, TypeSafe's System One [T1, L1]

- **What it is.** A model that answers questions about a given text (the "state") with probabilities, not generated text [T1]. It has three kinds of question:
  - `choice`: one of named options, with the probability of each and a confidence;
  - `score`: a level on an ordered scale, with probabilities;
  - `noul`: the probability that the answer is yes.
- **Its probabilities.** TypeSafe says they are trained to be calibrated, and that calibration "is measured across groups of predictions; it does not guarantee that an individual answer is correct".
- **What it cannot do.** It writes no text and extracts no values.
- **Its speed and cost, as the vendor reports them.** In TypeSafe's own cookbook a choice question took 114 ms and cost $0.000046, against 0.8 to 13 s for the language models it compared (UNVERIFIED).
- **Through Metis.**
  - The route is `/typesafe/v1/systemone` with model `jev-latest` [M5]; `/api/v1/meta` also lists `jev-reranker-latest` [L1].
  - On 2026-09-29, all 12 calls in two runs, at about 13:43 and 13:50 UTC, returned HTTP 402 from TypeSafe: «Your organization has no available TypeSafe API credits» (`evidence/probe-2026-09-29.json` and `evidence/trial-refusals-2026-09-29.json`).
  - That means Metis's own account at TypeSafe was empty, so jev could not be measured. Whether it reads Persian is unknown.
- **Where it could fit.** Questions with a fixed set of answers, where a calibrated probability decides what goes to review:
  - paint and body condition in free text (CS-52);
  - "are these two listings the same car?" for duplicate pairs (CS-55);
  - the intent of a plain-Farsi query (CS-62).

  Not numbers such as price and mileage: code (CS-34) and the language model extract those. On 2026-09-29 the owner decided to treat jev as unavailable, so nothing is planned around it.

### 8. When Metis is unavailable

- **The risk is real.**
  - Metis's SLA allows 10% monthly downtime and excludes upstream outages [M11].
  - Metis keeps a page for the case where the internet is cut or reduced to the national network [M7]. So losing the international link behind it is a case the provider itself plans for.
- **Inside Metis.**
  - `metis-gpt` and `metis-gpt-mini` are offered "for emergencies, when the internet is cut or becomes national" [M7]. `metis-gpt` answered valid JSON here (6 of 6) at $3.56 per 1,000 extractions.
  - Its error text is OpenAI's word for word: "Unsupported parameter: 'max_tokens' is not supported with this model. Use 'max_completion_tokens' instead." (`evidence/trial-refusals-2026-09-29.json`). So it is probably an OpenAI model behind Metis's gateway. Whether it keeps working during a shutdown is Metis's claim, UNVERIFIED.
  - Sotoon's Gemma 3 27B also answered valid JSON, slower and less accurately. Sotoon is an Iranian cloud, going by the provider's name; where the model runs is UNVERIFIED.
- **Outside Metis.** Two other Iranian gateways answered this machine with OpenAI-style errors when called without a key: AvalAI (`api.avalai.ir/v1`, 401 "Missing bearer authentication in header") and GapGPT (`api.gapgpt.app/v1`, 401 "Invalid token").
  - Both are reached through the ISP's own path, like Metis: 9 and 10 hops answer, and a TCP connection takes about 6 ms (`evidence/network-2026-09-29.json`).
  - So they are reachable from an Iranian network and follow OpenAI's format. Their catalogues, prices and terms were not studied.
- **In Carshenas.** Only query understanding (CS-62) and explanations (CS-64) call a model while a buyer waits.
  - Code parses everything a source structures (CS-34). Extraction and duplicate jobs can wait in the queue and retry.
  - So an outage delays AI work instead of breaking search. Plain-Farsi search can fall back to the filters.

## Recommendation

1. **Use Metis, as ADR-0019 records, through the native routes for structured output.**
   - `/openai/v1` with `response_format` json_schema strict.
   - `/anthropic` with `output_config.format`.
   - Gemini's `generateContent` with `responseJsonSchema`.
   - DeepSeek only in JSON mode, with the schema in the prompt.
   - Not the OpenAI-format wrappers to other providers, which drop the structured-output parameter.
2. **Keep the key in `.env` locally and in the server's secret store in production.** Log the answering model, the tokens and Metis's or the provider's request id, never the key or the listing text.
3. **Validate every answer in code, even though all 42 here were valid.** DeepSeek, the wrappers and the fallback models rely on the prompt alone. Feed a validation error back for a bounded number of retries, then send the listing to review (CS-44, CS-45).
4. **Record each call's tokens and price it from Metis's catalogue.** Report the cost in dollars and, separately, in tomans at the day's rate, since Metis bills that way.
5. **For CS-44,** the layer needs at least the OpenAI and Anthropic formats (Claude's structured output needs the Anthropic route), and preferably Gemini's. The three official SDKs and the OpenAI-compatible format all work against Metis.
6. **For CS-46,** the shortlist through Metis:
   - cheap: `gpt-5.6-luna`, `gemini-3.1-flash-lite`, `deepseek-v4-flash`, `mimo-v2.5`;
   - stronger: `claude-haiku-4.5`, `claude-sonnet-5`, `gpt-5.4-mini`;
   - fallbacks: another provider's model through Metis, and Sotoon's Gemma for when every foreign provider is unreachable. Never `metis-gpt`: the owner ruled it out on 2026-09-29 (ADR-0019).
7. **jev is treated as unavailable** (the owner's decision of 2026-09-29), and no question to Metis is planned.

The trade-off accepted: one Iranian company stands between Carshenas and every model, under a 90% SLA. In return there is one key, one bill in rials, and a service that works from Iran without a VPN.

What would change this recommendation:
- Metis failing at the demo's volume;
- a shutdown in which its fallback models do not answer;
- a gateway with a stronger SLA and the same routes.
