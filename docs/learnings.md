# Learnings

Append-only. One dated line per non-obvious lesson from a finished task that is not visible in the code itself, with the task ID (lessons inherited with the repository foundation carry the area they came from instead). `/plan` reads this before scoping similar work. Promote a line to the **Gotchas** section of `AGENTS.md` only if every future task must respect it; delete lines that stop being true.

- 2026-09-17 (tracking): Beads 1.3.0 stores issues in an embedded Dolt database and writes Codex/Cursor config plus git hooks on `bd init`; Backlog.md keeps one markdown file per task and its agent guides inside the CLI (`backlog instructions ...`), which is why it was chosen (ADR-0001).
- 2026-09-17 (browser tooling): `@playwright/test` 1.63 already bundles the agent CLI, MCP server, trace inspector and skills; the standalone `@playwright/cli` and `@playwright/mcp` pin an alpha Playwright with its own browser build, so never install them alongside.
- 2026-09-17 (browser tooling): Vercel agent-browser drops the zero-width non-joiner from Persian accessible names in snapshots; copy names only from Playwright snapshots.
- 2026-09-17 (browser tooling): the official Playwright container has no Persian UI font (falls back to FreeSerif); self-host the app's typeface or CI screenshots will never look like production.
- 2026-09-17 (browser tooling): `playwright install` garbage-collects browser builds no installation references, including other projects' on the same machine; use `pnpm browsers`, which passes `--no-remove`.
- 2026-09-17 (browser tooling): a credential scrubber keyed on parameter names alone will redact the page URL itself (analytics send it as `session…=`); require values to look opaque before scrubbing.
- 2026-09-18 (design harness): a new file in `.claude/agents/` is not callable as a subagent type immediately (the Agent tool answered "not found" right after the file was written and registered it a few minutes later); if it is unknown, run the same prompt through a general-purpose subagent instead of waiting.
- 2026-09-18 (design harness): `Intl` for `fa-IR` has three traps: `dateStyle: 'full'` prints «۱۴۰۵ شهریور ۲۷, جمعه», the `currency` style puts «ریال» before the number, and `NaN` renders as «ناعدد»; format with `long` plus your own weekday, append the unit yourself, and treat «ناعدد» on screen as a bug.
- 2026-09-18 (design harness): model vision cannot see a 2 px shift (0.07 % of pixels in a 160×60 box); measure spacing, sizes and contrast from the DOM (`playwright cli snapshot --boxes`, `eval`) and use screenshots only for gross problems.
- 2026-09-21 (react harness): path-scoped rules in `.claude/rules/` attach only when a matching file is opened with the Read tool; a fresh session that read code with `cat` or only created files got none of them, so the AGENTS.md map and `/work` name the packs explicitly.
- 2026-09-21 (react harness): Vitest without `globals` never runs Testing Library's automatic cleanup (a second render in a file sees the first); register `cleanup` in `vitest.setup.ts`. `import 'server-only'` resolves in Next builds but not in Vitest; alias it to `next/dist/compiled/server-only/empty.js`.
- 2026-09-21 (gorilla tests): fast-check's `interruptAfterTimeLimit` resolves while the run in flight keeps driving the page; with Playwright, enforce the time box between runs. A time box also makes a fixed seed machine-dependent, so anything that must be deterministic counts runs instead.
- 2026-09-26 (CS-1): robots.txt is not permission: Divar's robots.txt only blocks a few paths, but its terms of use forbid any automated copying of ads, and Karnameh allows listing pages while disallowing their photos; read the terms and the robots rules per source before crawling (ADR-0008).
- 2026-09-26 (CS-1): torob.com answers automated clients with its own CAPTCHA (HTTP 490); study Torob from archived pages, its engineering blog and its careers API, never by crawling it.
- 2026-09-26 (CS-1): a capture that succeeds can still be a block page: DataDome answered a CarGurus results page with HTTP 200, then laid «Access is temporarily restricted» over an intact DOM, so the accessibility tree and the tokens looked normal and only the screenshots showed it. Open the first-view screenshot before trusting any capture; the tool now also stops on requests to challenge-only hosts (`captcha-delivery.com`).
- 2026-09-26 (CS-26, CS-27): the App Router renders with Next.js's bundled React canary, not the React in `package.json`, while Vitest uses the one in `package.json`; with the pin at 19.2.8, `<ViewTransition>` worked in pages but was missing in unit tests. When a React API behaves differently in tests and pages, compare `next/dist/compiled/react` with the pinned version (CS-27 moved the pin to 19.3.0).
- 2026-09-26 (CS-26): a skeleton that renders the component's own frame still drifted: on a 412 px phone the real facts line wrapped and rows came out 20 px taller, and a 4:3 thumbnail in a flex row stretched to the row's height (stretch overrides `aspect-ratio`). Give every slot a fixed line count and aspect frames `self-start`, then measure both row heights.
- 2026-09-26 (CS-26): behind `useOptimistic`, `revalidateTag(tag, 'max')` made a saved bookmark jump back 451 ms after the tap (stale-while-revalidate sends no re-render), and a reload still served the stale value; `updateTag` held. Every action behind an optimistic control uses `updateTag` or `refresh()`.
- 2026-09-26 (CS-26): `playwright cli run-code --filename` wraps the file in parentheses and runs it in a bare VM context: the file must be one function expression with no trailing semicolon (so it is in `.prettierignore`), and outside `page.evaluate` there is no `console` or `setTimeout`.
