The page where the product earns trust: why this price is a good or a bad deal, based on which cars, and whether the same car is cheaper elsewhere.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The price analysis draws the five deal bands as one continuous bar with a marker at this listing's price, the market value with its date and method, and an info control that explains the bands from the shared definitions; a listing with a market value but no rating shows the marker against the value with the reason and no band
- [x] #2 The explanation is generated by code from stored facts through templates (no language model, so no credit and no invented number): a test proves every number in a rendered explanation comes from the database rows, and a labelled sample of 30 listings reports a faithfulness rate
- [x] #3 Comparables (each linking to its own listing page), price history with days on market, condition chips with their source sentence, the seller's declared condition and risk flags are shown. The duplicate group (cheapest first) is not built: CS-55 and a second source do not exist, so the page has no placeholder for it
- [x] #4 The primary action clicks out to the source listing, and on a phone it stays in reach
- [x] #5 Playwright tests cover the page on phone and desktop (right-to-left, no sideways scroll, axe, the unrated reason, the re-check request), and it is added to e2e/fixtures/app-pages.ts
- [x] #6 The main photo is the first listing_photo row, loaded from the source's own https address with no referrer and never through the optimizer or stored (ADR-0025); the other photos are a gallery; a photo that does not load shows the same-size placeholder
- [x] #7 The page says when the listing was last checked; opening one whose last check is older than the freshness window records a re-check request (CS-35) and says so quietly, and a listing found gone says so plainly and offers similar listings
- [x] #8 A missing listing answers a real HTTP 404, and a malformed percent-escape in the address answers a Farsi 404 instead of the framework's plain English 500, both proved in a browser test
- [x] #9 Result cards on the search page lead to /listings/[id], and the page's data loader is one documented module that CS-65 and CS-67 reuse
